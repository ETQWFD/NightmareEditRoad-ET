本版是 405 的收尾 + 你要的画质档位。

1. 新增画质档位 1K / 2K / 3K / 4K
- 位置：「设置 → 画质（输出分辨率）」。成片长边分别 1024 / 2048 / 3072 / 4096。
- 说清楚实现：手机本地引擎不可能原生跑 4K 扩散，所以引擎仍按你机型的原生尺寸生成（这台机器约 256–768px），再分步放大到成片分辨率。4K 是“放大输出”，细节上限由原生尺寸决定，不会凭空变清晰。
- 低内存 / 32 位机型会自动降档（32 位最高 2K、6GB 以下最高 2K），并在设置里明确写出“已从 X K 降档”，避免保存那一刻 OOM 把整批结果弄丢。
- 修改页顶部与配置卡会同时显示：画质档位（成片 px）+ 原生 px，避免再出现“显示 40 步实际 8 步”这类信息不一致。

2. 画笔蒙版不再“报喜不报忧”
- 生成完会用蒙版自身做一次校验：只在“你没圈到的区域”比对源图与结果，如果差异过大（说明引擎整图重画了），直接在界面上提示“该模型可能不支持蒙版，这张是整图重绘，建议把重绘强度调到 30% 左右”。不再让你猜画笔到底有没有生效。

3. 收尾上一版遗留
- 极低配机型步数不再被钉死 8 步（改为最多 20 步、长边仍 256 保内存）；设置页「低配机保护」可强制按你自己的参数跑。
- 重绘强度、反推理负面提示语、提示语联想、画笔选区、1K–4K 全部走同一份偏好存储，升级不会重置。
- 标定与预计时间改用新键，旧的被污染数值一次性作废；CPU 占用读不到系统数据时用本进程 CPU 时间兜底。

4. 其他
- 修图结果、队列、选区、画质设置全部落本地，熄屏 / 切页 / 被系统回收后可续跑。
- 失败仍弹可复制日志窗。

需要真机确认：4K 在你这台机器上的实际耗时与内存表现（若保存失败会有明确提示）；蒙版校验是否触发提示。有异常请把日志复制发我。
