本版针对你列的几件事逐条改：

1. 上传图片不再被压成 1024（“上传进去就很模糊”的根因）
- 以前无论选什么画质，源图一律压到 1024 长边再修，细节在进引擎前就丢了。
- 现在按画质档位保留：1K→1536、2K→2048、3K→3072、4K→4096（受内存/32 位限制，最高 4096）。原图 8K 也能按你选的档位保留更多细节。
- 引擎实际扩散尺寸同步提高：高配机型 2K/3K/4K 档给到 1024 长边（SD1.5 再往上会明显失真），低配仍按 256/384 保稳定。

2. 提示语更容易“改得动”
- 只要提示语里出现“换成 / 改成 / 背景 / 场景 / 服装 / 头发 / 表情 / 姿势 / 去掉 / 加上”这类改动意图，本批自动把重绘强度提到 70%（引擎上限），并在修改页明确写出“已自动提高强度”。
- 想做画质微调就写空提示语或把强度调低；想要大改就保持自动。

3. 图标不再又粗又大
- 405 版为了“看得见”把字放大到 1.14 倍、笔画 86，结果显得笨重。本版回调到 0.92 倍、笔画 56，四周留出呼吸空间，字仍然清晰（背景仍是冷白玻璃）。

4. 补上“灵动”动画
- 底部四栏：选中缩放 + 底色渐入 + 按压回弹（spring 动画）。
- 修改页：总进度与单张进度都做缓动，不再一格一格跳；提示条改为淡入+展开、淡出+收起。

5. 线程
- 上限固定 16（手动可选 2/4/6/8/12/16，另有“自动（大核数）”），不会再出现负数或超过核心数的值。

6. 其他
- 画质 1K–4K、重绘强度、反推理、联想、画笔选区、步数（默认 40、10–100）全部在设置里，升级不重置。
- 蒙版自检保留：引擎若整图重画会直接提示，不再让你猜。

真机需确认：4K 档在你这台机器上的保存耗时；自动提高强度后人物一致性是否还能接受（不能就调低强度或用画笔圈区域）。
