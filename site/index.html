NERT · Nightmare Edit Road
手机本地 AI 修图

不用登录、没有额度、不上传任何图片。下载或导入一个模型，剩下的全在手机里跑： 批量改图、实时预览、精确预计时间、自动存相册。32 位与 64 位原生引擎都已打进安装包。

下载最新版 APK 安装与常见问题 自建加速服务端

Requires Android 9+（minSdk 28）。安装包内含 armeabi-v7a 与 arm64-v8a 两套 libstable_diffusion_core.so，低配老机与旗舰机都是同一个 APK。

这一版做了什么

从「能跑的修图器」变成「日常能用的修图器」：引擎不再假死，出错不再静默。

引擎

修图不中断、不丢图

批量任务移出界面生命周期，由独立控制器执行，并有修图保活前台服务。切到历史 / 设置不会中断，熄屏与切后台同样继续跑；图片在选定时就复制进应用私有目录，即使进程被系统收回，重新打开也能“继续修完（N 张）”。

启动

修 rememberCoroutineScope left the composition

旧实现把循环挂在 Compose 作用域上，一离开页面就被取消并抛异常；现在由控制器持有作用域，异常路径全部收敛为可读日志。

诊断

失败必弹日志窗

任何一步失败（引擎加载、模型缺失、内存不足、超时、无首步进度）都会弹窗，内含设备/ABI/内存/模型/线程/引擎日志，可一键复制或关闭。

模型

可以自己导入

本地 .safetensors / .ckpt 在手机里直接转换，或粘贴 HuggingFace 链接下载。导入的模型与下载模型一样能进入修图页。

修图页

顶部点模型名即可切换

下载或导入多个模型后，在修图页顶部打开列表切换；修图进行中禁止切换，避免引擎与模型不匹配。

步数与强度

默认 40 步，强度可调

尺寸、CFG、调度器出厂配好；步数（10–100）与重绘强度（30%–70%）由你决定。改不动就调高，只想微调画质就调低。

历史只留结果

上传 8K 也保留细节

选 1K/2K/3K/4K 时，源图分别按 1536/2048/3072/4096 长边保留（受内存与 32 位限制），不再一律压到 1024。

按你的话改

说要改就自动加力度

提示语里出现“换成/背景/服装/去掉/加上”等改动意图时，本批自动把重绘强度提到 70%，并在修改页说明原因。

画质 1K–4K

成片分辨率自己选

设置里可选 1K / 2K / 3K / 4K（长边 1024 / 2048 / 3072 / 4096）。引擎按机型原生尺寸生成后分步放大到成片分辨率；4K 属于放大输出，内存不足或 32 位机型会自动降档并写明。

画笔选区

只改你圈出来的地方

修改页每张图都有画笔。圈住要改的区域，圈外像素保持原样；选区会随任务保存，熄屏、切页、被系统回收都能接着跑。

中文 / English

提示语直接写中文

本地词典覆盖场景、动作、服装、发型、光线、道具约 300 条，输入时还有联想候选；词典没覆盖的词会明确告诉你，不再悄悄丢掉。

反向词

畸形、血腥、丑陋是底线

设置里的「反推理（负面提示语）」可以自己加词或清空，但畸形人物、血腥、丑陋这三条始终强制生效，关不掉。

界面

白色半透明玻璃

弃用动态取色，固定冷白板 + 毛玻璃卡片；底部常驻四栏：模型 / 历史 / 修改 / 设置，右上角入口取消。

性能

低 / 中 / 高配都能加速

大核数自动识别，可在设置里的 CPU 压力面板手动指定线程数并跑 6 秒压力测试；输出长边按内存分档（384/512/640/768）。

语言

提示语中英都行

中文提示语自动翻译后再进模型；翻译失败会退回内置离线词典，不会因此中断修图。

下载

下载源可切换

设置里在「自动 / 国内镜像 / 官方」之间切换，应用内三语言（简中 / 繁中 / English）与下载源都已回归。

更新

检查更新走新仓库

api.github.com/repos/ETQWFD/NightmareEditRoad-ET/releases/latest，并按本机 ABI 选包。

精简

只留修图与模型下载

生成、图片社区、聊天社区、登录、额度、音乐、图片上传全部移除；无用的后台服务与页面一并去掉。

机型对照

三步开始

1. 装好并下模型

安装 APK → 首页选一个模型（约 1.2 GB）→ 等待下载与转换完成。

2. 点模型进修图

下载完点它，或底部「修改」→ 选图片（可多张）→ 写提示语 → 开始修图。

3. 自动进相册

每张修完自动写入 Pictures/噩梦修改之路-ET，底部「历史」随时回看。
