怎么安装 / 装完打不开

1）在 Releases 下载 NERT_*.apk（一个 APK 同时含 32 位与 64 位原生库，老机新机都是同一个包）。

2）首次安装允许“未知来源”。安装后打开，系统只会问两件事：Android 13+ 的通知权限（用于下载/修图进度），Android 9/10 的存储权限（用于读写图片）。

  • 打不开 / 秒退：卸载重装，或把 Android/data/etc.editroad.et 与下载目录里的残留删掉再装。
  • MIUI / ColorOS / OriginOS：在电池设置里把 NERT 设为“无限制”，否则锁屏后会被系统杀掉（表现为修图突然不动）。
模型下载太慢、失败，或者想用自己下载的模型

下载：首页列表点模型 → 确认体积 → 下载。设置里可以切换下载源：自动（按网络择优）、国内镜像、官方源。镜像不通时手动换成官方源，反之亦然。

自己导入：首页“自己导入模型”卡片 →

  • 本地文件：选手机里的 .safetensors / .ckpt（SD1.5 架构），应用会在本机转换成可用格式，进度显示在首页卡片里，可以切到别的页面，转换不会中断。
  • 链接导入：粘贴 HuggingFace 的模型链接，应用会登记成一个自定义模型并开始下载 + 转换。
  • 导入的模型同样出现在修图页顶部的切换列表里，也能随时切回去。

注意：SDXL、Flux、DiT 等新架构以及 NPU 专用包不能用于本机修图链路，导入后只会出现在完整模型列表，不会进入修图切换列表。

进度一直是 0%、按钮显示“修图中…”却不动

这一版已经把“假 0%”当成缺陷处理：修图由独立的批量控制器执行，界面只订阅它的状态，所以不再有“离开页面就把任务取消”的问题（旧版报 rememberCoroutineScope left the composition）。

现在如果引擎没起来，会明确告诉你原因并弹日志窗：

  • 200 秒内引擎没就绪 → 弹窗会给出引擎启动日志末尾、退出码含义（137=内存不足被系统杀，134/139=原生崩溃）、内存与存储余量。
  • 连上了但 150 秒没有第一个 step → 判定为引擎无首步进度，弹窗带请求参数与端口状态。
  • 某个 step 后 20 分钟不动 → 判定卡死，主动结束并弹日志。

自查顺序：换一个更小的模型 → 设置里把渲染器从 GPU 改成 CPU → 设置里的 CPU 压力面板把线程数调成“大核数”→ 关掉其它占用内存的应用。

提示“模型引擎无法加载”

常见三种：

  • 模型文件不完整：日志窗里会列出模型目录文件清单。缺 vae / unet / text_encoder 时，回首页对该模型重新下载或重新导入。
  • 内存不够：32 位进程可用内存有限。日志窗会显示总内存、可用内存、位数与线程数；把步数降到 20–30、一次只修 1 张。
  • GPU 驱动不兼容：设置里把渲染器切到 CPU；应用本身也会在 GPU 失败时回退 CPU，并把 gpu_unstable 记进日志。
“预计剩余时间”准不准

第一张是估算：按 实测单步耗时 × 步数 × 队列张数，没有实测值时按机型档位给保守估算。

每完成一张，应用会实测这一步的真实耗时并记住（editroad_ms_per_step），后续同一机型的预计就会明显贴合实际。切到别的标签页或锁屏期间产生的耗时也会被算进去，不会“预计 27 秒然后一动不动”。

如果你发现预计长期偏大或偏小，把日志窗内容发我，我按机型再调系数。

生成中途切页面会不会中断

不会。底部四栏（模型 / 历史 / 修改 / 设置）都是常驻的，切换时不销毁任务；生成中切换模型会被拒绝并提示，避免修到一半换模型。设置里的 CPU 压力面板还会实时显示“修图中 x%（i/N 张）”。

步数该设多少

默认 40，滑杆可设 10–100，另有 20 / 30 / 40 / 60 / 80 快捷档。经验：

步数适合代价
10–20快速试构图、低配手机细节偏软
30–50日常修图（推荐区间）耗时线性增长
60–100发丝、织物、手部等细节中低配手机耗时明显增加，画质收益递减

尺寸、CFG、重绘强度和防畸形反向词都不需要你手动填：输出长边按运行内存自动选（384 / 512 / 640 / 768），一次最多 16 张，超过 1536 长边的原图会先等比缩放。

低配 / 中配 / 高配怎么更快
  • 低配（3–4 GB、32 位）：渲染器选 CPU，步数 20–30，一次 1 张，线程数设 2–4。
  • 中配（6 GB）：默认自动（优先 GPU，失败回退 CPU），步数 40。
  • 高配（10 GB+）：可以放心 60–100 步 + 批量，设置里的 CPU 压力面板用 6 秒压力测试确认大核都在跑。
  • 线程数设为“自动”时会用大核数；手动改小可降温，改大不一定更快（小核拖慢整体）。
提示语能不能写中文？界面语言怎么换

提示语中文、英文都可以，也可以中英混写。中文提示语会先翻译成模型能理解的英文再进模型；翻译服务不可用时会退回内置离线词典，不会因此失败。留空则只做画质增强，几乎不动原图内容。

界面语言在设置页切换：简体中文 / 繁體中文 / English（三档）。切换后建议重启一次应用，个别文字来自静态文案。

检查更新走的是哪里

设置页“检查更新”读取新仓库的最新发布：api.github.com/repos/ETQWFD/NightmareEditRoad-ET/releases/latest， 并按本机 CPU 架构选择对应安装包。若提示“无法获取版本信息”，多数是网络不通（无法访问 api.github.com），可以换网络或挂代理再试。
