服务端（可选）

手机 App 完全不需要服务端就能修图。服务端是给「想在同一台电脑或局域网里用 HTTP 出图」的人准备的可选组件： 它把本地引擎包成一个兼容 sdapi / OpenAI images 接口的小服务，本机跑，不出公网也可用。

它是什么 / 不再是什么

是一个单二进制本地服务：Go 主程序 + 随包引擎，监听 127.0.0.1:7860（端口可改），把请求转给本机模型出图。

这一版已经去掉与修图无关的东西：没有社区、没有聊天、没有额度/签到/兑换、没有登录鉴权后台，也去掉了根路径自动跳转的网页出图控制台。 只保留健康检查与出图接口，接口越少越稳。

服务端不是必需的。手机 App 的模型下载走 GitHub 官方源与镜像源，与这个服务端无关；两者不要混用。

接口

方法 / 路径作用说明
GET /healthz健康检查返回引擎与模型状态，用于脚本与监控；该路径不打请求日志。
POST /sdapi/v1/txt2img文生图A1111 兼容字段：prompt、negative_prompt、steps、cfg_scale、width、height、seed、sampler_name。
POST /sdapi/v1/img2img图生图 / 修图在 txt2img 字段基础上加 init_images（base64）与 denoising_strength。手机端修图用的就是这条链路。
POST /v1/images/generationsOpenAI 兼容方便直接接入现成工具链，返回 b64_json。

已移除

/admin 网页出图控制台、/admin/generate、/admin/cancel、/admin/key/rotate 这类后台接口不再暴露； /api/txt2img、/api/img2img 别名与根路径跳转也一并去掉，避免误以为有个"管理后台"。

构建与运行

Go 1.23+，在仓库 server-go/ 目录：

# Linux
GOOS=linux GOARCH=amd64 go build -o nert-server-linux-amd64 .

# Windows
GOOS=windows GOARCH=amd64 go build -o nert-server-windows-amd64.exe .

# 运行（模型放 models/，引擎放 bin/）
./nert-server-linux-amd64

目录约定

nert-server/
├── config.json     # port / model_path / engine_path 等
├── models/         # .safetensors / .ckpt / .gguf，支持子目录
└── bin/            # 引擎可执行文件

启动日志会打印实际使用的模型；没找到模型时会提示把权重丢进 models/。出图耗时可能几分钟，因此写超时必须为 0（不超时）， 反向代理（Nginx / Cloudflare Tunnel）也要把读超时放宽。

安全提示

默认监听 0.0.0.0 的历史配置已在配置里显式控制。只在可信网络里开放端口；需要远程时用 SSH 隧道 ssh -L 7860:127.0.0.1:7860 user@host，不要把端口直接暴露到公网，也不要在服务端存放任何用户图片。
